# PFAS Input Comparator (prototype)

Interactive prototype of the comparative PFAS mass-input calculator proposed as a
data-driven subtask for WRF RFP 5413, *Comparison of PFAS Contributions to
Agricultural Systems*.

The page shows the intended form of the tool: one calculator with three audience
views (farmer, utility, regulator), a plain-language front end that maps a question
to calculator inputs, and outputs that always carry their uncertainty and a full
computation record.

**All values are illustrative placeholders.** Concentration distributions, retention
factors, and record counts stand in for the project database and models; nothing on
the page is a measurement or a project result. The tool estimates mass input and
environmental fate only. It does not assess exposure, health risk, or regulatory
compliance.

Single static page, no build step: open `index.html` or visit the GitHub Pages site.
